## 主题推导要求

基于核心策略和游戏项目特性，推导出**3-5个传播主题方案**供用户选择。

### 游戏主题特殊要求
- 主题需契合目标玩家群体的"语言体系"和文化认同
- 考虑主题与游戏世界观/角色/玩法的深度绑定
- 评估主题在游戏社区（TapTap/NGA/贴吧/QQ群）的传播力
- 兼顾"核心玩家认同"和"泛用户认知"的平衡
- 考虑主题对下载/回流/付费等核心指标的驱动

### 推导逻辑
1. 从游戏核心体验/情感价值出发
2. 找到品牌/产品与玩家情感的连接点
3. 用玩家能共鸣的语言进行主题表达
4. 验证在核心社区和公域平台的双向穿透力
