## 竞品营销分析

请搜索竞品最近3-6个月的营销动态，进行深度对标分析：

1. **竞品识别与分级**：明确直接竞品（2-3家）、间接竞品（1-2家），说明选择理由
2. **营销策略拆解**：竞品的核心传播策略、主打平台、创意方向、投放力度
3. **内容案例分析**：竞品近期爆款内容（播放/互动数据）、内容形式、成功原因分析
4. **达人合作模式**：竞品合作的典型KOL类型、合作形式、频次
5. **差异化机会**：竞品策略中的"空白地带"和我方可差异化突破的方向

**搜索方向：** 竞品品牌名+营销/广告/传播/合作、竞品社交媒体账号动态、行业营销案例盘点
**输出要求：** 以对比表格+文字分析结合呈现，最后总结"竞品启示与我方差异化方向"
