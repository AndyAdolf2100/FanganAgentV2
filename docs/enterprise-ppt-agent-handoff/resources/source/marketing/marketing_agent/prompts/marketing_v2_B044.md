## 人群策略制定

制定人群分层触达与运营策略：

1. **人群分层定义**：以表格形式呈现各层人群
   - 核心层（种子用户）：精准画像 + 规模预估 + 触达优先级
   - 兴趣层（潜力用户）：画像特征 + 规模预估 + 转化策略
   - 泛人群层（声量贡献）：特征描述 + 参与方式 + 拉新策略
2. **分层触达策略**：每层人群用什么渠道、什么内容、什么频次触达
3. **转化链路设计**：各层人群从"看到"到"行动"的完整路径（配合平台工具）
4. **人群流转机制**：如何将泛人群逐步转化为核心人群（如抖音5A模型/小红书KFS）

**输出要求：** 人群策略必须与传播策略和内容策略对应——每层人群看什么内容、在什么触点被触达、最终完成什么行为
