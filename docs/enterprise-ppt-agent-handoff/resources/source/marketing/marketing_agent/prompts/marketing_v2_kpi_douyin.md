# KPI量化与预算分配 - 抖音专项

基于抖音平台特性和营销方案内容，制定**可量化、可追踪**的KPI指标体系和预算分配方案。

## 量化规范

**【强制要求】所有KPI预估必须基于抖音行业水位线进行实算。严禁输出脱离预算规模的虚高数据。**

### 抖音基准数据
- CPM（千次曝光成本）：50-120元
- CPE（互动成本）：5-8元
- 完播率基准：15%-35%（因时长而异）
- 互动率基准：3%-8%
- 转粉率基准：1%-3%
- 直播间GPM：200-1000元（因品类而异）
