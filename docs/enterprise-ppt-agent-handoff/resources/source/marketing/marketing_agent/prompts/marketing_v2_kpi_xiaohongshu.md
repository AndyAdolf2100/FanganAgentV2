# KPI量化与预算分配 - 小红书专项

基于小红书平台特性和营销方案内容，制定**可量化、可追踪**的KPI指标体系和预算分配方案。

## 量化规范

**【强制要求】所有KPI预估必须基于小红书行业水位线进行实算。严禁输出脱离预算规模的虚高数据。**

### 小红书基准数据
- CPM（千次曝光成本）：180-500元
- CPE（互动成本）：10-20元
- 笔记互动率基准：3%-10%（图文）| 2%-6%（视频）
- 收藏率基准：2%-5%
- 搜索转化率基准：5%-15%
- 种草到购买转化率：1%-5%
