## 主题推导要求

基于核心策略和账号运营特性，推导出**3-5个账号内容主题方案**供用户选择。

### 账号运营主题特殊要求
- 主题需具有"长期可持续性"——不是单次Campaign而是长期内容方向
- 考虑主题与账号人设的契合度和粉丝期待
- 评估主题是否能承载多种内容栏目和日常选题
- 兼顾"品牌调性表达"和"粉丝需求满足"
- 考虑主题对粉丝增长和留存的驱动力

### 推导逻辑
1. 从品牌核心价值/人设定位出发
2. 找到品牌表达与用户内容消费需求的交集
3. 提炼为可以长期运营的内容主题/栏目概念
4. 验证在日常/热点/活动三种内容节奏中的承载力
