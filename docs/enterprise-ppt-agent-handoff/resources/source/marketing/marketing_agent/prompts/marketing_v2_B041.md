## 传播策略制定

制定完整的传播策略框架（需与核心策略逻辑一致）：

1. **传播目标分层**：
   - 认知目标：让xx人群知道xx（量化指标）
   - 好感目标：建立xx品牌认知联想（定性指标）
   - 行动目标：驱动xx转化行为（量化指标）
2. **传播节奏规划**：以表格形式呈现
   - 预热期（占比xx%时间）：核心任务 + 关键动作
   - 爆发期（占比xx%时间）：核心任务 + 关键动作
   - 延续期（占比xx%时间）：核心任务 + 关键动作
3. **传播矩阵**：各平台/渠道在传播中的角色定位和协同关系
4. **触达频次策略**：核心人群的触达频次目标和触达路径设计

**输出要求：** 传播策略必须可量化、可排期，用表格呈现节奏规划，让执行团队清楚"什么时间做什么"
