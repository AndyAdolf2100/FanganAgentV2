## 达人策略制定

使用搜索工具查找真实达人信息，制定可执行的达人合作策略：

1. **达人矩阵架构**：以表格形式呈现
   - 头部KOL（500万+）：数量、预算占比、核心角色（品牌背书/事件引爆）
   - 中腰部KOL（50-500万）：数量、预算占比、核心角色（话题扩散/深度种草）
   - KOC/尾部（1-50万）：数量、预算占比、核心角色（口碑铺量/真实体验）
2. **达人选择标准**：
   - 硬性标准：粉丝画像匹配度≥X%、互动率≥X%、无竞品合作冲突
   - 软性标准：内容风格适配、创意共创能力、粉丝粘性
3. **具体达人推荐**：搜索并推荐具体达人（名称、平台、粉丝量、内容方向、推荐理由、预估报价）
4. **合作形式明细**：每类达人的具体合作形式（定制视频/直播/图文/话题参与）和内容方向
5. **发布节奏**：配合传播各阶段的达人内容发布编排表
6. **效果预估**：各层级预期CPE、总互动预估、ROI参考

**搜索方向：** 目标品类+达人推荐、平台达人排行、同行业品牌达人合作案例
**输出要求：** 必须给出具体的达人推荐（不能只说"建议合作头部达人"），用表格呈现达人矩阵和推荐名单
