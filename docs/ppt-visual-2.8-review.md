# 2.8 视觉流程补齐与小米项目重做

日期：2026-09-28。项目：9a94d350759747969c58447557477089。

## 之前为什么明显不如轻芽

上一份小米 PPT 复用了 118 研究后适配的策划、来源校验、逐页 HTML、探针与 PPTX 导出流程，但没有达到轻芽版本的视觉完成度。它不是 118 的原始生成引擎，也不能将工程检查通过等同于审美通过。

轻芽 2.5 有三张人工策划的专属场景图、六个经截图和 PowerPoint 审阅的重点页，以及人工压缩过的正文。这些人工编辑没有充分固化进自动流程。小米 2.7 的实测是：零配图、32 页原始规划、只有两个重点页通过，随后容量纠错将其拆成 43 页。

具体缺陷：

1. 原素材复用仅对轻芽案例生效。火山生图开关仍关闭，小米没有可用素材。无图仍然可以“完成”，界面未明确提示。
2. 逐页模型把标签标记为正文，校验反复报“角色不能降级”，浪费六次修复请求后回退。
3. 固定母版要求文字槽位完全匹配，四项受众无法复用三项母版。四个重点页限制还错误地限制了无需付费的母版使用。
4. 缺少整体文案编辑环节，封面、结尾和指标页信息过密。拆页被当成主要解决方式。

## 本轮代码修改

- `marketing_agent/presentation_editorial.py`：增加一次有缓存、无付费重试的主编步骤，压缩正文、收紧封面/结尾容量、安排图片与语义构图。指标 value 逐项锁定，不允许引入新数字；完整原稿仍保留在备注。所有更改进入位置日志。
- `marketing_agent/presentation_images.py`：增加按文稿 SHA256 绑定的项目素材集合，保留来源与提示词，避免跨品牌误用；无图状态进入任务与界面提示。
- `marketing_agent/presentation_pages.py`：宿主按文字字段确定角色；图片引用支持注册过的语义名称；免费母版可覆盖全部匹配页面，单独限制付费自定义页。
- `marketing_agent/presentation_masters.py`：受众横带、平台分工、阶段排期、信息屋支持二至四项的适配母版，不再仅能套轻芽案例的固定槽位。
- `presentation/design.css`：四指标改为两行两列，避免四个狭窄数值栏与连环拆页。
- `marketing_agent/presentation.py`、`frontend/src.js`：2.8 接入主编步骤、图片状态和新版重生成时的旧规划复用。
