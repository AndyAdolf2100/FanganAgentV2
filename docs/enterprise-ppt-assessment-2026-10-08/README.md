## 当前完整链路

1. **前端导入与打标。** 仅接收16:9 PPTX；前端解析页面、母版/版式继承、文字、图片和形状，形成HTML快照。Seed按单张图提供观察，GLM结合结构给出标签建议，用户确认后发布模板版本。自动标签是参考，人工标记需保留。
2. **文稿规划与选版。** GLM提取标题、汇报人/导师/时间、章节目录及页面分配。来源块必须完整覆盖。只有明确序言标题范围内的内容才能进入序言页。明确且完全匹配的原稿目录由正式目录承接，避免重复正文目录；不明确的情况保留来源，不静默删除。
3. **理解所选模板并制定约束。** 先选择模板，再分析模板截图与元素，明确受保护品牌/背景、标题外框、正文自由区及主题。模板资料已按版本缓存，提供几何、声明字体和标签等事实；缺容量/视觉证据时明确unknown。
4. **素材准备。** GLM规划图片用途；Seedream生图；Seed单图验收。通过的素材以别名提供给页面生成，已有素材复用缓存。通常在对应HTML生成前完成，不是最后机械补图。统计图用真实来源表格数据，不用生成图片冒充。
5. **模型完整生成HTML。** GLM使用企业skill、原模板参考、约束、文稿和素材，输出完整页面HTML。正文可组织图文、表格和图表，必要时续页；固定页和品牌保持约束。工具不代替模型拼正文版式。
6. **先硬检查，再单图视觉检查。** 来源、编号、品牌、模板几何、资源、正文范围、溢出等先由代码/浏览器检查。合法候选再交Seed看截图，检查裁切、重叠、对比、文字与SVG间距、层级等。每次模型请求仍是一张图；当前代码允许多个单图请求有界并发，默认5路、最高10路，不代表单次发送多图。
7. **分类纠错与升级。** JSON/来源/固定区域错误分别处理；Seed格式或复验不确定时保持HTML重查。明确局部问题只修改定位区域，非目标DOM及图表数据保留。反复出现且有容量实证时，允许GLM重排正文、换同套正文模板、重析约束或分页。每组首次尝试后最多3轮纠错；终审后另有最多1轮受影响组修复，不能理解成整份任务总共只调用3次。
8. **版本冻结、整册审查和交付。** 保存候选、检查结果、问题ID及提交版本；冻结后独立逐页终审，GLM根据各页观察与测量进行全册一致性检查。当前代码可复用未改变页面的独立终审证据，变化页重新审。来源、浏览器、视觉、素材、历史问题及导出版本等均通过才ready_for_delivery=true。

## 主要扣分点

### 1. 上游模板还原仍可能丢信息

`marketing/frontend/enterprise/parser.ts:265`跳过SVG/EMF/WMF图片，`:411`跳过部分图表、表格和嵌入对象。后续分析比较的是重建HTML，不能证明与原PPTX一致。字体保留名称与实际加载也需区分。这会限制“N套企业模板通用”。

### 2. 确认了一处轮廓品牌强制保护缺口

`marketing/frontend/enterprise/Editor.vue:111`手工设置轮廓文字用途时写入artworkTextRole；`marketing/marketing_agent/enterprise/model_html.py:127`的人工品牌必锁检查只读取textRole。离线构造同类元素后，模型合同遗漏该品牌仍能通过contract_check。此项是确定的校验覆盖缺口，不是已经观察到生产稿品牌被删除。应优先统一品牌语义，再补跨前端标签到合同的回归。

### 3. 选版与设计仍偏向生成后修复

当前先规划选模板，再分析所选模板截图和合同。新增layout_profile有帮助，但标题实际容量、图表适配、形状内部安全区通常还是unknown。应该先得到足够的模板资料再选版，减少拿不合适版式反复调整。局部scope无法唯一定位或涉及跨区CSS/SVG依赖时会明确降级，不能声称局部DOM锁保证像素外观完全不变。

### 4. 视觉通过不等于高级设计

此次第25页的标签完整可读，配图存在，不能继续把旧版裁字当作这份文件的现存问题。第8页文字与下方节奏说明仍有重复；第20页大箭头视觉重量高；第25页中间文字区较窄。当前更擅长保证可读与企业风格，而对信息压缩、视觉节奏、图形尺度和版式选择仍缺系统审美基准。

### 5. 缺少当前版本的完整交付验证

已有严格ready_for_delivery门禁，但本次未找到可确认的当前版本整册通过证据。PPTX导出包含栅格装饰、可编辑普通文字及部分原生图表，`pptx_application_render`仍pending；HTML截图一致不等于PowerPoint实际显示一致。若重点交付网页，应分别定义网页验收与PPTX验收，当前门禁仍强制要求PPTX存在。

## 优先顺序

1. 修复手工轮廓品牌强制保护遗漏，确保企业固定元素约束覆盖完整。
2. 用当前代码完成一份真实整册的独立终审与人工抽查，收集真实耗时、修复次数和未关闭问题，而非继续凭功能数量判断完成度。
3. 前置模板还原损失、字体及版式容量资料，建立至少几套结构不同的企业模板回归样本。
4. 再优化首次布局和内容表达，降低重复与返修；已有错误分类、局部修复和目录去重不需要重做。
