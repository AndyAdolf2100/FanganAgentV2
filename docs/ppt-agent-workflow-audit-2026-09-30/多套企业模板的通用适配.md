# 多套企业模板的通用适配

更新：2026-09-30。本文记录通用设计约束、实际实现和尚未证明的能力，不把某一套模板的改善视作全部模板通过。

## 目标与原则

同一条项目 Agent 工作流读取不同的企业模板快照，不为每个企业、页码或形状开发一个填框生成器。GLM负责理解、选择、分页和完整HTML；Seed负责单图观察与复验；Seedream只生成需要的素材。Codex负责研发和独立检查，不写生产页。

前端继续承担PPTX解析、拆页、HTML快照、标签应用及模板发布。生成过程只读已发布版本；普通网页PPT入口不变。

## 每套模板带什么，通用工具做什么

| 模板提供的事实 | 通用 Agent / 工具处理 |
| --- | --- |
| 当前模板字体、颜色、元素坐标、形状与截图 | GLM提取这套模板的约束，不能复用上一套企业的主题或固定字号 |
| 页用途和人工品牌标签 | 自动标签可被模型结合证据重新理解；人工品牌锁不可解除 |
| 当前正文变体和可用空间 | GLM根据文稿结构选择、重排或更换同套正文变体 |
| SVG路径、CSS图形、图片、组合组件 | 浏览器提供位置、变换、裁剪和关联文字证据；Seed判断实际可读区域 |
| 标题左对齐、居中、右对齐 | 从原快照段落align计算扩宽锚点；保持y/height、基线和品牌，先验合同后生成 |
| 实际文稿节点和数据 | 组件数量随内容决定；不沿用示例数量，不补造节点或数据 |
| 每轮截图及人工问题 | 绑定HTML与截图版本；重新分页后复验当前来源组的所有页 |

标题、正文图形、背景并不是同一种约束：标题保持该模板的排版语言，正文组件可以调整，真正品牌及固定页继续保护。某套模板出现40px标题，不等于其他模板都用40px。

## 不依赖形状名单的修复路径

1. 结合HTML、前端标签和模板截图，区分背景、品牌、标题、可编辑组件与配套说明。
2. 比较真实文字宽度、行数、换行标记、子容器、图形比例与可用空间。外接矩形不是形状的内部文字安全区。
3. GLM根据问题选择移除多余断行、利用空白、等比放大组件、重排说明、换同套正文变体或分页。具体动作不按圆形/箭头/菱形硬编码。
4. 分别检查图内标签与图外说明：图内字须避开孔洞、透明区、轮廓和裁剪；图外说明可以独立排版，但关联、对齐与对比必须清楚。
5. 来源、品牌和浏览器硬检通过后，Seed逐张复验具体问题；再做独立终审。普通pass不能替代原问题逐项关闭。

正文唯一的`data-enterprise-body`是外层容器，内部允许多列、嵌套与不规则组件组合；它不是要求所有文字塞在同一个矩形。组件内部安全区未测得时应保留unknown并依赖实际截图复核，不假装已完成数学验证。

## 本轮通用性补强

- 检查未发现针对第8/13/20页的代码分支或统一40px标题规则。这几页只作为问题样本和复验输入。
- 标题扩宽从仅向右变为依据原模板左/中/右对齐锚点扩宽。左右新增区域都检查固定前景碰撞，人工品牌和固定页不放宽。
- 图形测量扩展至CSS装饰及SVG组合/变换，并区分可实测几何与未知填充安全区。测量只提供事实，不自动改HTML或宣称美观通过。
- 诊断与项目skill使用通用组件表述，允许内置标签和外置说明两种设计；优先保持轮廓比例，避免把图形压扁。
- 人工问题保持稳定ID和原始来源映射；复验范围覆盖当前来源组每一页，避免新增续页或内容迁移后问题丢失。缺项、uncertain和预算不足继续待审。

具体实现：`enterprise/model_html.py`、`enterprise/pipeline.py`、`enterprise/diagnostics.py`、`presentation/enterprise.mjs`及`enterprise-deck`项目skill。上线状态和实际测试结果以[实施与验收记录](企业工作流v5实施与验收.md)为准；在途worker不会因为源码更新自动完整加载新代码。

## 能力边界与验收样本

“通用流程”不等于已证明任意PPTX都能无人干预还原并美化。目前明确边界：

- 仅16:9；正常前端导入统一到1200px宽。特殊字体、复杂组合、转曲文字与原PPTX还原误差仍需导入检查。
- 正文合同目前要求一个保留标题和一个外层正文矩形。内部多栏/不规则内容可以表达；完全无标题、复杂侧标题或多个互不连通自由区的合同仍需进一步扩展验证。
- 生产文字必须是真实DOM文字，不用SVG text、图片文字或CSS content代替来源。原模板合并成图片且混有必须替换文字时，不能声称已经具备原生可编辑能力。
- 混合对齐、无明确文字锚点及旋转标题不自动扩框，继续沿用原框并交模型决定其他合法修复。
- 任意SVG/clip-path/mask的精确内部填充安全区没有完整几何求解器，浏览器事实加Seed仍可能漏判，因此保留独立终审与待复核状态。
- 工程回归中的合成多形状样本证明测量和约束行为；不能当作多套真实企业模板的模型审美验收。

后续应固定一组真实样本：浅/深背景、左/中/右标题、圆/环/多边形/任意路径、CSS裁剪、组合旋转、时间轴/流程、表格/统计图、长短文稿及分页。按来源完整、品牌保留、文字可读、构图协调、跨页一致和人工介入率验收，而不是只看是否成功导出。
