## 一、项目判断与传播任务

小米汽车已经从单一车型进入轿车与 SUV 并行的产品阶段。小米集团披露，2026年上半年智能电动汽车交付量为185,055辆。对于下一阶段传播，单纯重复发布会参数与热度，难以替代真实的生活体验。用户需要更具体地理解：哪一款车适合自己的日常，坐进车里之后又有什么不同。

本方案选择新一代 Xiaomi SU7 与 Xiaomi YU7 作为传播主角。SU7 连接个人驾驶、通勤与城市生活，YU7 连接多人同行、周末出游与更丰富的装载场景。两条叙事共同落在“小米汽车如何进入人的真实生活”这一问题上。

传播任务分为三个层次：让潜在人群看懂双车差异，让有兴趣的人愿意预约并完成试驾，让完成体验的人获得清晰、可信的购买信息。传播结果以有效线索和到店体验衡量，不以曝光量代替用户行动。

## 二、目标人群与双车定位

第一类是城市探索者。他们看重车辆设计、驾驶体验和日常通勤的情绪价值，常在短视频、汽车社区和搜索平台比较车型。对这类人，SU7 的内容重点应是“每天都想开的车”：城市道路、停车、上下班与周末短途的完整体验，而不是孤立的加速数字。

第二类是共同出行家庭。他们关注多人乘坐、后备厢使用、长途舒适度，以及家人是否容易上手。对这类人，YU7 的内容重点应是“让同行更从容”：带孩子、带朋友、带行李的真实出发与抵达。具体空间、续航和配置展示必须逐项核对官方资料与试驾车版本。

第三类是小米生态用户。他们熟悉小米手机与智能家居，但不一定了解汽车与既有设备如何协同。沟通重点是用真实操作演示“人、车、家”场景，并同时解释适用条件；不把概念化联动当作所有车型、所有设备都已支持的功能。

双车定位不是给用户贴标签，而是提供一个选择方法：今天更多是“自己开”，还是“和重要的人一起走”？让用户先选生活场景，再通过试驾验证车型判断。

## 三、核心创意与内容体系

传播主题：一城两程，开出你的下一程。

主视觉以同一座城市的两个时段展开：清晨的城市道路，一人驾驶 SU7 开始高效而有节奏的一天；傍晚和周末，YU7 载着同行者驶向更远的目的地。画面强调人的表情、上车动作、车内互动和到达后的生活，不把车辆悬空摆拍作为主要表达。

品牌短片《两种出发》采用交叉叙事：同一个家庭中，两位主角各有自己的行程，最终在周末的共同出发中相遇。片尾邀请观众回答“你的下一程，和谁一起？”该短片承担情绪记忆，车型功能仍由后续实测内容解释。

内容矩阵分三层。第一层为30秒情绪短片和高识别度视觉海报，负责建立主题；第二层为“真实一程”系列，用通勤、接送、周末出游三个场景展示可核验体验；第三层为车型选择卡与试驾问答，回答空间、配置、补能、服务和试驾流程等实际问题。所有参数卡都保留车型版本、测试条件和资料日期。

用户共创话题为「我的下一程」。邀请车主与试驾者记录真实的一段路：起点、同行者、为什么出发，以及车辆在这段路中帮了什么忙。优先选择有细节、有局限、有真实感受的内容，不要求统一好评话术；商业合作内容清晰标识。

## 四、六城体验与渠道转化

线下以北京、上海、广州、深圳、杭州、成都六城为方案试点，具体门店与场地以品牌实际资源和审批为准。每城设计两条试驾路线：一条覆盖城市通勤场景，一条覆盖周末多人出行场景。路线要兼顾安全、可比性与真实道路条件，不安排危险驾驶或不合规拍摄。

体验活动采用“先选行程，再选车”的接待流程。用户在预约页回答同行人数、常见路线和重点关注问题；到店后由工作人员提供适合的双车对照建议；试驾结束后，用户得到一张个人体验记录卡，列出已体验项目、尚未验证的问题和官方查询入口。记录卡不是自动销售承诺。

线上渠道承担不同任务。小米自有渠道发布权威信息和预约入口；短视频平台传播“真实一程”场景内容；汽车社区承载长测与问题讨论；搜索渠道覆盖车型比较、试驾预约和本地门店查询；私域仅对已授权联系的用户提供预约提醒和后续答疑。所有入口统一到可追踪的预约页，避免用户在不同渠道重复填表。

达人合作以三类角色搭配：汽车专业创作者验证驾驶与配置，生活方式创作者展示城市与周末场景，真实车主补充长期使用细节。合作前提供统一事实核查表，允许表达主观体验，不允许将未经核实的参数、辅助驾驶能力或续航表现作为确定承诺。

## 五、十周执行节奏

第1—2周为准备期。完成双车产品信息核验、城市资源排期、试驾路线安全评估、创意拍摄和预约页联调。建立素材审批清单和客服常见问题库，先用内部小范围试运行检查预约到店链路。

第3—4周为引爆期。发布《两种出发》主片和两组城市海报，同时上线六城活动预约。首批专业体验内容集中回答“SU7 和 YU7 如何选”，把主片带来的兴趣转入可验证的信息与实际体验。

第5—8周为体验期。六城每城计划开展六场小规模试驾体验，共36场。每周发布真实路线短片、车主故事与常见问题回应，按预约率、到店率和试驾反馈调整素材与时间段。线下体验优先保证服务质量，不为了冲场次压缩讲解与试驾时间。

第9—10周为收口期。集中发布用户共创作品与试驾反馈摘要，对尚未到店的已授权预约者进行一次有用的信息提醒。活动结束后对比两款车型的人群匹配、线索质量与内容表现，提出下一轮城市和渠道的保留或调整建议。

## 六、预算、指标与复盘

本方案以十周、六城、总预算300万元作为讨论基线。下表为策划假设，不代表小米汽车实际投放计划。预算优先保障真实体验、可复用内容和效果归因。

| 预算项目 | 金额（万元） | 用途 |
| --- | ---: | --- |
| 内容制作与达人合作 | 90 | 主片、场景短片、专业评测和车主故事 |
| 媒体投放与搜索承接 | 75 | 场景内容放大、车型比较与本地预约 |
| 六城试驾体验 | 80 | 场地、执行、路线、安全与用户接待 |
| 创意物料与页面开发 | 25 | 海报、体验记录卡、预约页和问答页 |
| 数据监测与用户研究 | 15 | 归因、问卷、访谈和结案分析 |
| 机动费用 | 15 | 城市资源与执行变更预留 |
| 合计 | 300 | 十周整合营销项目 |

目标指标同样属于方案假设，需在正式执行前结合门店承载能力和历史转化基线确认。

| 指标 | 十周目标 | 统计口径 |
| --- | ---: | --- |
| 有效留资 | 8,000条 | 去重、授权且联系方式可用 |
| 试驾预约 | 2,400人 | 用户主动提交且选择具体城市或门店 |
| 到店完成试驾 | 1,800人 | 门店系统记录实际完成 |
| 预约到店率 | 75% | 完成试驾人数 ÷ 试驾预约人数 |
| 试驾后问题解决率 | 85% | 用户反馈问题在约定时间内获得明确答复 |
| 整体有效线索成本 | 不高于375元/条 | 300万元总预算 ÷ 有效留资量 |

每周复盘同时看数量与质量：曝光是否带来车型理解，预约是否转化为到店，试驾后是否还存在信息盲点。若某城预约高、到店低，先检查时段、距离和提醒方式；若到店多、满意度低，优先调整路线与接待；若某车型内容热度高但线索不匹配，重新审视内容场景而不是单纯加投。

项目成效不以“必然带来多少订单”作承诺。订单受价格、配置、交付、门店能力等多因素影响，应由品牌销售系统另行核算，并与本次活动的有效线索、试驾数据作关联分析。

## 结语与待确认事项

“一城两程”希望让用户从看见一辆车，走向理解自己真正需要的一段路。内容负责激发向往，试驾负责验证体验，清晰的信息负责帮助用户做决定。
