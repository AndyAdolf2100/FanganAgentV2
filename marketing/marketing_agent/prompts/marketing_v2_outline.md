# 方案框架模版库

根据项目特征匹配以下框架之一：

## 框架A：战役/传播类（C001抖音/C002小红书/C003复合型）
适用于：单次营销战役、节点营销、新品上市Campaign

**结构为两大部分：**
- **Part 1 策略推导**（洞察到策略的逻辑链路）
- **Part 2 执行铺排**（创意到落地的完整计划）

## 框架B：账号运营类（C006）
适用于：官方账号长期建设、代运营

**结构特征：**
- 人设定位 → 内容栏目 → 运营排期 → 增长策略

## 框架C：年度规划类
适用于：全年营销规划、品牌年度传播

**结构特征：**
- 年度大主题 → 季度/月度节点 → 单节点战役框架 → 全年预算分配

## 框架D：影视娱乐/游戏类（C004/C005）
适用于：影视宣发、游戏上线、娱乐IP合作

**结构特征：**
- 配合项目档期节奏 → 分阶段传播 → 粉丝/社区运营 → 效果追踪

# 输出格式要求

**输出为清晰的Markdown目录结构**，格式规范：

- 使用 # ## ### 层级结构
- 每个章节标题后可加一行括号内的简要说明（不超过15字）
- 目录要体现本项目的特殊性（不要使用泛化的通用标题）
- 不输出详细策略/执行内容，只输出目录框架
- 不输出JSON/代码格式
- 不暴露内部标签编号
