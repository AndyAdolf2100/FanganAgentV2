# 项目 PPT Agent 自主流程

本文件依据118第18–21轮、xiaofang-methodology和ppt-guardian-pro适配；不是118私有执行器或隐藏提示词的复刻。

项目入口接收完整文稿与选定风格后，自动执行：原稿快照与语义块 → 匹配已有图片 → 主Agent通过视觉工具读取样例 → 将视觉DNA、比例与留白写入规划和逐页brief → 分页与容量编辑 → 图片任务单 → generate_image/edit_image → 页面HTML生成/母版复用 → 浏览器探针 → HTML/PPTX与截图 → 分批看图 → 主Agent决定修复工具 → 页面Agent修版 → 再渲染和看图 → 输出成品及未完成事项。

工具负责实际执行，模型负责内容、图片用途、构图与纠错决策。依赖顺序、路径约束、预算、文案/数值锁定、原生图表、检查和导出由宿主保证。不得把host工具称为另一个人工操作员，也不得把固定排版检查冒称模型审美。

所有生成与质量判断在项目内完成；不得依赖Codex另写本项目文案、图片提示词、单页HTML，或依赖Codex先看图再指定生产修复。开发测试可以验证程序，但不是每份PPT的运行步骤。

每次视觉工具最多看5张实际页面截图，主Agent要把问题转成具体工具参数；不能只声称“已优化”。修复保留全部锁定文案、数据、来源与完整备注。删除文字的建议改成层级、行列、空间分配；不能执行删除。图片工具失败不付费重试；页面工具失败可依据反馈有限修正。所有动作和失败写日志。

一次最多2轮视觉修版，每轮最多3页、每页最多2次HTML尝试。先处理中高优先级，低优先级意见保留，不能抢占必要修复的名额。修复后必须重新看修改页；失败恢复上一个可导出版本。预算不足、工具错误、无法满足原生图表约束时输出明确待办，禁止宣称质量通过。

本项目采用全册首轮渲染后分批复核；118建议的生成中每3–5页回看、影响后续页面的在线编排尚未完全等价。原生图表保留数据结构，不将其转成自定义HTML逃避检查。
